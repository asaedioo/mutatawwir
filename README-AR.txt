مُتطوّر - نسخة مشاركة التقدم

ارفع محتويات هذا المجلد إلى جذر مستودع GitHub Pages واستبدل index.html وsw.js وmanifest.webmanifest والرموز القديمة.

ميزة جديدة: زر «مشاركة التقدم» ينشئ صورة PNG من بيانات التمارين الحالية، ويعرض قائمة المشاركة على Android إذا كان المتصفح يدعم مشاركة الملفات. إذا لم يدعمها، ينزّل الصورة لتشاركها من المعرض.

بعد الرفع، افتح الموقع ثم حدّثه. إذا بقيت النسخة القديمة بسبب التخزين المؤقت، أغلق التطبيق وافتحه مجددًا أو امسح cache الموقع فقط (لا تمسح بيانات الموقع/التخزين المحلي حتى لا تفقد التمارين).
