مُتطوّر - مشاركة التقدم بتصاميم رياضية متنوعة

ميزة المشاركة تولّد صورة PNG من بيانات تمارينك الحالية، وتختار عشوائياً واحدة من ثلاث خلفيات رياضية (عضلات الظهر، تمرين الدمبل، والعقلة). الأرقام والمنحنى تُرسم من سجلّك المحلي وليست أرقاماً ثابتة.

ارفع جميع محتويات هذا المجلد إلى جذر مستودع GitHub Pages، مع استبدال index.html وsw.js والملفات القديمة وإضافة scene-1.jpg وscene-2.jpg وscene-3.jpg. لا ترفع ملف ZIP نفسه إلى جذر الموقع.

بعد الرفع، انتظر نشر GitHub Pages ثم أغلق التطبيق وافتحه مجدداً. إذا بقيت النسخة القديمة، امسح cache الموقع فقط؛ لا تمسح بيانات الموقع أو التخزين المحلي حتى لا تفقد سجل التمارين.

بيانات التمارين تبقى محفوظة محلياً على جهازك.
